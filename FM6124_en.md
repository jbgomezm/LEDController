**16-Channel Dual-Buffer Constant Current Output LED Driver IC**
**FM6124 (Document Number: S&CIC1501)**

**Overview**
The FM6124 is a driver IC specifically designed for LED modules and displays, featuring a 16-channel constant current output drive capability. It utilizes a patented "output clamping" technology that effectively eliminates the first-line dimming phenomenon and prevents damage to the LED beads. The FM6124 features an enhanced blanking design for excellent blanking performance. Additionally, the FM6124 has exceptional anti-interference characteristics, ensuring that the constant current and low-grayscale effects are not impacted by the PCB board. The output current can be arbitrarily adjusted using different external resistors to precisely control LED brightness. During the display process (at the falling edge of OE), the FM6124 caches 16-bit display data, allowing the system to continue storing 16-bit serial data while the FM6124 is displaying; this increases the refresh rate by over 50% compared to standard constant current source chips. The FM6124 employs precise current control technology internally, achieving an inter-chip error of less than ±3.5% and an inter-channel error of less than ±2%.

**Application Information**
The FM6124 uses precise current drive control technology, ensuring minimal current variance between different channels on the same chip and between different chips.

1. Channel-to-channel current difference is <±2%, and chip-to-chip current difference is <±3.5%.


2. It features an output current characteristic that is unaffected by the load terminal voltage. The output current will not change with variations in the LED forward voltage (VF).



**Adjusting Output Current**
The FM6124 adjusts the output current (Iout) through an external resistor (Rext). The calculation formula is:
$V_{R-EXT} = 1.191V$
$Iout = (V_{R-EXT} / Rext) * 15$
